🆘 PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════════════════

PROBLEMA: "Permission denied (publickey)"
SOLUÇÃO: Use HTTPS ao invés de SSH
         URL: https://github.com/usuario/repo.git

PROBLEMA: "Repository not found"
SOLUÇÃO: Certifique-se de ter criado o repositório no GitHub primeiro

PROBLEMA: "! [rejected] main -> main"
SOLUÇÃO: git pull origin main --rebase
         git push origin main

PROBLEMA: "Large files detected"
SOLUÇÃO: Arquivos maiores que 100MB não são permitidos
         Remova com: git rm --cached arquivo_grande
